How 2D and UI Art Is Made

Visual 🚪 One-way door High stakes

The look of menus, health bars, inventory slots, dialogue boxes, icons and fonts. The logic behind them stays plain code that Claude writes directly; this is about how they look, which only shows up on screen. Godot builds UI from a Theme (styles for panels, buttons and frames) that is plain text the studio can write; on the web, UI over three.js is best done as HTML and CSS. Nothing exists that turns one set of design values into both.

The case against my pick

AI-written SVG icons are reliable only in simple, geometric styles; benchmarks show quality drops sharply on detailed icons, so richly illustrated item icons may still need packs or another route. Generating both a Godot Theme and web CSS from one source is a small compiler to maintain, and no existing tool does it. For a game with very little UI, B's recoloured pack covers it in an afternoon.

Assumptions and tripwires

  • UI settings derive from the look lab record (decision 29), so changing the look restyles the UI.
  • Icons written to the SVG subset Godot renders (SVG Tiny), and rendered and scored before use.
  • Fonts limited to open licences (OFL) and logged in the credits.
  • Tripwire: if icons look inconsistent after scoring, switch that game to a CC0 icon pack, recoloured.

Research context

  • Godot's Theme and its panel and frame styles are plain text resources; no tool turns design values into them, so the studio would write them.Godot Theme Maker
  • On the web, an HTML/CSS overlay over three.js gives real text, accessibility and the same design values as CSS variables.pmndrs uikit (in-canvas alternative)
  • Godot renders SVG icons through ThorVG (SVG Tiny only); since 4.5 it can re-render them at any size.Godot forum
  • AI-written SVG quality drops on complex icons; rendering and scoring each icon is the reliable pattern.UniSVG
  • Icon licences: game-icons.net needs per-author credit (CC BY 3.0); Kenney is CC0.game-icons.net
  • Godot's pseudolocalisation lengthens text automatically, which makes an overflow check possible.Godot docs
  • Contrast minimums are 4.5:1 for text and 3:1 for large text and controls; tap targets at least 24 px, ideally 44–48.WCAG 2.2
