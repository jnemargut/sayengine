The case against my pick

Terrarium's own worst files (main.js at 5,343 lines, buildings.js at 3,761) are what "one thing that grows" turns into without strict edges. A town is gigabytes of LiDAR and thousands of buildings; a daemon built for one stool may get slow or fragile, and one crash takes every tool down with it. B lets parallel agents build tools without stepping on each other, and nothing in A stops that from becoming a tangle. If you expect most of these tools to be thrown away after one game, B's "small and disposable" is worth more than a shared undo.

Assumptions and tripwires

  • Assumes modules can be kept apart by folder and by tool group (each with its own skill), with heavy data streamed from disk, not held in the daemon's memory.
  • Tripwire: if building one town makes ordinary /studio edits slower than about 200 ms, move world building into a worker process (still one scene format) before going further.
  • Tripwire: if Claude regularly picks the wrong tool, cut the always-loaded set back to /studio plus the one module in use.

Research context

  • Houdini stays one app around a node graph; heavy work runs headless (hython --pdg), and SideFX deprecated its separate TOPs app, folding it back in.SideFX docs
  • NVIDIA retired the Omniverse Launcher and its separate apps (Oct 2025) for one Kit SDK with extensions, keeping the shared format.NVIDIA
  • Remedy retired its old editor and rebuilt Northlight on one shared scene description with plugin tools.Remedy
  • Blender 4.2 moved most bundled add-ons out to an extensions platform with declared permissions: smaller core, modules around it.BlenderNation
  • Godot plugins break between minor versions (4.0→4.1 binary break; 4.4's uid:// change silently broke plugins).Godot 4.1 upgrade notesGodot forum
  • Tool count costs agents: 58 tools across 5 servers cost about 55K tokens; loading tools on demand cut usage about 85% and raised accuracy from 79.5% to 88.1% (Opus 4.5). Wrong-tool picks are the most common failure.Anthropic
  • Retrieving tools before the call raised tool selection accuracy from 13.6% to 43.1% in a study.arXiv 2505.03275
  • Godot has no native USD import and recommends glTF, so keep your own scene format and export glTF.Godot import formats

Where experts disagree

SideFX sells "pipeline in a box", while its users say big studios keep their own pipelines around Houdini. And the number of tools where agents start choosing badly isn't settled: blogs put it anywhere from 20 to 120. I found no clean write-up of a tool family drifting apart on formats, so the case against B rests on Terrarium's own evidence more than on outside sources.
