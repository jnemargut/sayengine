The case against my pick

This is a lean, not a strong pick — Soft Premium vs Technical Documentary is close. Every serious 3D tool (Blender, Maya, Houdini, Plasticity) defaults to dark for good reasons: long sessions, glare, and models popping against a dark surround; a light stone UI may tire power users and look unserious to them. And the people most likely to try a brand-new AI-first modeling tool in its first months are technical — exactly who Option B speaks to. Tiebreaker: if the first 50 users are AI developers driving it through Claude Code, take B; if they're designers who never learned Blender, take A.

This recommendation assumes

  • The north-star user is the "creative director" from the original vision, not the technical artist
  • The viewport surround stays neutral so material colors read truthfully
  • A dark variant of the same tokens ships later (tokens make this cheap)
  • Technical depth (code view, raw values) lives one click away rather than always on screen
  • Tripwire: if early users repeatedly ask for dark mode or call it too soft for real work, add the dark variant before any new features

Where experts disagree

3D-tool veterans insist on dark UIs; product designers point out that tools aimed at newcomers increasingly default light because it reads as approachable and keeps colors true. The deciding condition is who you're courting first — and since tokens are exported either way, switching later is a palette swap, not a rebuild.
