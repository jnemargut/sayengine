Technical 🚪 One-way door Medium stakes

Five skills (decision 35) need a home. Today your x-skills live in ~/.claude/skills and also ship publicly in decision-kit's X tier. The case against my pick

"When it's finished" may be a long way off, and until then nobody else can use even the planning half, which doesn't need the studio at all. Someone who only wants game planning would have to clone a 3D studio to get it. C gets the planning skills in front of people now, through decision-kit, with the studio hand-off switching on later. And a repo that holds both tools and skills is one more reason the studio could grow into one big tangle (the decision 26 worry).

Assumptions and tripwires

  • Assumes an install step (./studio install-skills, linking into ~/.claude/skills) so the skills follow the repo's version.
  • Assumes the build skill still degrades to plain Godot or three.js steps when the studio daemon isn't running.
  • Assumes decision-kit's validator runs on these skills in the studio's tests, so they stay portable.
  • Tripwire: if someone asks for the planning skills without the studio, publish them as a decision-kit game tier (C) that points at the studio for building.
