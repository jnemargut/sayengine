# Character craft and appeal pass

The "before" and "after" images use the same cameras. The "before" set is the Phase 7 models (`checkpoint-phase7/cast/*.glb`) re-rendered with the current cast player.

- `before/` and `after/` each hold:
  - `lineup.png`: the whole cast
  - `bodies.png`: full-body portraits, one per character
  - `faces.png`: head-and-shoulders close-ups
- `forge-lesson/`: the wide strike shot before and after, in Godot and on the web, plus the recut MP4s for both engines.
- `motions/`: the heron's flap and walk and the dog's sit and trot, with Phase 7's flap and sit for comparison.

## The three changes that mattered most, per character

| Character | Biggest changes |
|---|---|
| Blacksmith | Square shape language (boxy head, broad jaw, squared torso); bigger padded hands; belt, buckle and sleeve hems that read against the apron |
| Apprentice | Arms and legs with taper and volume instead of tubes; long-sleeve cuffs and belt; bigger, wider-set eyes |
| Goblin Shopkeeper | Triangle head (wide skull, narrow chin) with bar brows; oversized hands; value plan (dark red shirt, light apron, one gold accent) |
| Robot Porter | Rebuilt on the human plan with a square shape language (a solid body instead of a lanky frame); blocky torso with belt and accent buckle; heavier forearms |
| Marsh Bird | Bird legs (scaled shank, joint bands, splayed toes) instead of trousers; a plumage skirt over the hips; no belt (the body reads as feathers) |
| Kid | Head refinement scaled so the chibi stays in budget; bigger hands; belt and sleeve cuffs with a red accent |
| Elder | Long-sleeve cuffs and belt; bigger eyes; brows on a brow ridge |
| Dog | Floppy ears; a shorter, boxier muzzle with a broad dark nose pad; a deeper barrel |
| Heron Courier | Bird legs (a thin yellow shank, no grey trousers); layered feather wings (secondaries, fanned primaries, coverts); a flap that shows both wings from the side |
